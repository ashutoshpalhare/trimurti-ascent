# Trimurti Arts, Commerce & Science College — Official Website

A modern, mobile-first website for **Trimurti Arts, Commerce & Science College**, designed to reflect academic excellence, build trust with prospective students and parents, and streamline the admissions journey.

Built with **TanStack Start**, **React 19**, **Vite 7**, and **Tailwind CSS v4**, the site delivers a premium university-grade experience comparable to top NAAC-accredited institutions in India.

---

## ✨ Highlights

- **Premium academic design** — Deep blue (`#0F2D52`) + gold (`#D4A437`) palette with glassmorphism, soft shadows, and elegant gradients
- **Mobile-first & fully responsive** — Tested across phones, tablets, and desktops
- **Sticky mega-menu navigation** with smooth scroll transitions
- **Animated counters, scroll reveals, and hover effects** for a lively, modern feel
- **SEO-optimized** — unique titles, meta descriptions, and semantic HTML on every route
- **Floating WhatsApp CTA** for instant admission inquiries
- **Integrated admission inquiry form** and contact map
- **Accessible & semantic** — proper headings, alt text, ARIA labels

## 🛠️ Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) v1 (file-based routing, SSR-ready)
- **UI:** React 19 + TypeScript
- **Build:** Vite 7
- **Styling:** Tailwind CSS v4 (theme tokens in `src/styles.css`)
- **Components:** shadcn/ui + custom academic components
- **Icons:** lucide-react
- **Fonts:** Poppins (display) + Inter (body)
- **Deploy target:** Cloudflare Workers (edge)

## 🚀 Getting Started

### Prerequisites
- [Bun](https://bun.sh) (recommended) or Node.js 20+

### Install & Run

```bash
# Install dependencies
bun install

# Start the dev server
bun run dev
```

The app will be available at **http://localhost:8080**.

### Build for Production

```bash
bun run build
```

## 🎨 Design System

Design tokens are defined in `src/styles.css` and consumed via Tailwind utilities:

| Token | Value | Usage |
| --- | --- | --- |
| `--primary` | `#0F2D52` | Headings, primary CTAs, navigation |
| `--gold` | `#D4A437` | Accent buttons, highlights, "Apply Now" |
| `--accent` | `#2563EB` | Links, secondary actions |
| `gradient-primary` | Deep-blue gradient | Hero overlays, logo mark |
| `gradient-gold` | Gold gradient | Premium CTAs |
| `glass` | Frosted blur | Sticky header on scroll |

Typography: **Poppins** for display headings, **Inter** for body copy — loaded from Google Fonts in `__root.tsx`.

---

## 🔧 Customization

- **Brand colors:** edit CSS variables in `src/styles.css`
- **Navigation links:** edit the `nav` array in `src/components/site/Header.tsx`
- **Contact details / WhatsApp number:** update `Footer.tsx` and `WhatsAppButton.tsx`
- **Programs & fees:** edit content in `src/routes/courses.tsx` and `src/routes/admissions.tsx`
- **Gallery images:** drop new files into `src/assets/` and import in `src/routes/index.tsx` / `campus.tsx`

---

## 📦 Deployment

The project is configured for **Cloudflare Workers** out of the box via the TanStack Start nitro preset. You can also deploy to any platform that supports Vite + Node SSR (Vercel, Netlify, Render).

Build output is generated by `bun run build` and ready to serve.
